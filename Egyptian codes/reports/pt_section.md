## خطوات الحساب

### الضغط المسبق المتوسط

**1. fpc = Pe / A**
- المعادلة: `fpc = Pe/(b·h)`
- التعويض: `1600×10³/(3500×250)`
- النتيجة: **1.829 MPa**
- المرجع: ACI 318-19 8.6.2.1 (أقل ضغط مسبق متوسط 0.9 MPa) (PDF page 181)

### إجهاد الكابلات

**2. إجهاد الشد عند الجاك**
- المعادلة: `fpj = Pj/Aps`
- التعويض: `2300×10³/1680`
- النتيجة: **1,369.048 MPa**
- المرجع: ACI 318-19 Table 20.3.2.5.1 (0.94fpy و 0.80fpu عند الشد، 0.70fpu بعد النقل) (PDF page 591)

**3. الإجهاد بعد النقل**
- المعادلة: `fpi = Pi/Aps`
- التعويض: `1850×10³/1680`
- النتيجة: **1,101.19 MPa**
- المرجع: ACI 318-19 Table 20.3.2.5.1 (0.94fpy و 0.80fpu عند الشد، 0.70fpu بعد النقل) (PDF page 591)

### مرحلة النقل (Pi + الوزن الذاتي)

**4. النقل: العزم الصافي**
- المعادلة: `Mnet = Mext + M2 − P·e`
- التعويض: `120.0 + 28.9 − 1850×0.075`
- النتيجة: **10.156 kN·m**

**5. النقل: إجهاد الألياف العلوية**
- المعادلة: `ftop = −P/A − Mnet/S`
- النتيجة: **-2.393 MPa**

**6. النقل: إجهاد الألياف السفلية**
- المعادلة: `fbot = −P/A + Mnet/S`
- النتيجة: **-1.836 MPa**

### مرحلة التشغيل (Pe + كل الأحمال)

**7. التشغيل الكلي: العزم الصافي**
- المعادلة: `Mnet = Mext + M2 − P·e`
- التعويض: `235.0 + 25.0 − 1600×0.075`
- النتيجة: **140 kN·m**

**8. التشغيل الكلي: إجهاد الألياف العلوية**
- المعادلة: `ftop = −P/A − Mnet/S`
- النتيجة: **-5.669 MPa**

**9. التشغيل الكلي: إجهاد الألياف السفلية**
- المعادلة: `fbot = −P/A + Mnet/S`
- النتيجة: **2.011 MPa**

**10. التشغيل المستديم: العزم الصافي**
- المعادلة: `Mnet = Mext + M2 − P·e`
- التعويض: `182.5 + 25.0 − 1600×0.075`
- النتيجة: **87.5 kN·m**

**11. التشغيل المستديم: إجهاد الألياف العلوية**
- المعادلة: `ftop = −P/A − Mnet/S`
- النتيجة: **-4.229 MPa**

**12. التشغيل المستديم: إجهاد الألياف السفلية**
- المعادلة: `fbot = −P/A + Mnet/S`
- النتيجة: **0.571 MPa**

### أقل تسليح عادي مترابط

**13. قوة الشد Nc**
- المعادلة: `Nc = ½·ft·y·b ، y = h·ft/(ft + fc)`
- التعويض: `0.5×2.011×65.5×3500`
- النتيجة: **230.476 kN**
- المرجع: ACI 318-19 Table 8.6.2.3 (أقل تسليح مترابط في البلاطات ذات الاتجاهين) (PDF page 182)

**14. As,min**
- المعادلة: `As,min = Nc / (0.5 fy)`
- التعويض: `230.5×10³/(0.5×420.0)`
- النتيجة: **1,097.506 mm²**
- المرجع: ACI 318-19 Table 8.6.2.3 (أقل تسليح مترابط في البلاطات ذات الاتجاهين) (PDF page 182)

### المقاومة القصوى للعزم

**15. العزم الأقصى Mu**
- المعادلة: `max|1.2D + 1.6L + 1.0M2 , 1.4D + 1.0M2| (بإشارة المنطقة)`
- التعويض: `1.2×165 + 1.6×70 + 25`
- النتيجة: **335 kN·m**
- المرجع: ACI 318-19 Table 5.3.1 Eq. (5.3.1a,b): U = 1.4D ، U = 1.2D + 1.6L (PDF page 103)

**16. عمق الكابل من وش الضغط dp**
- المعادلة: `dp = h/2 ± e`
- التعويض: `250/2 + 75`
- النتيجة: **200 mm**

**17. fps (غير مترابطة، ℓn/h = 32.0)**
- المعادلة: `min(fse + 70 + fc′/(100ρp) , fse + 420 , fpy)`
- التعويض: `min(1168 , 1372 , 1674)  fse=952 ρp=0.00240`
- النتيجة: **1,168.214 MPa**
- المرجع: ACI 318-19 Table 20.3.2.4.1 (fps للكابلات غير المترابطة) (PDF page 591)

**18. β1**
- المعادلة: `Table 22.2.2.4.3`
- التعويض: `fc′ = 35`
- النتيجة: **0.8 **
- المرجع: ACI 318-19 Table 22.2.2.4.3 (β1) (PDF page 615)

**19. عمق كتلة الضغط a**
- المعادلة: `a = (Aps·fps + As·fy)/(0.85 fc′·b)`
- التعويض: `(1680×1168 + 1098×420.0)/(0.85×35×3500)`
- النتيجة: **23.275 mm**

**20. φMn**
- المعادلة: `φ[Aps·fps(dp − a/2) + As·fy(ds − a/2)] ، φ = 0.90`
- التعويض: `0.9×465.3`
- النتيجة: **418.738 kN·m**
- المرجع: ACI 318-19 Table 21.2.1 (φ = 0.90 انحناء مضبوط بالشد، 0.75 قص) (PDF page 605)
