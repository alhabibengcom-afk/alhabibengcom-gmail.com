# تحليل وتصميم العناصر الخرسانية — ECP 203-2020 و ACI 318-19

مكتبة Python ومعاها Agent لـ Claude Code.

**قاعدة المكتب:** الكود المصري ECP 203-2020 لكل العناصر، **ما عدا بلاطات البوست تنشن، بالكود الأمريكي ACI 318-19.**

### الكود المصري (`ecp203/`)

| العنصر | اللي بيتحسب |
|---|---|
| **الكمرات** (`ecp203/beam.py`) | الانحناء (قطاع مستطيل أو T، تسليح مفرد أو مزدوج، cmax، الحد الأدنى للتسليح)، القص (qu,max و qcu والكانات) |
| **الأعمدة** (`ecp203/column.py`) | النحافة والعزوم الإضافية، أقل لامركزية، معادلة 4-12-a، منحنى التفاعل بتوافق الانفعالات، حدود التسليح، الكانات |
| **القواعد المنفصلة** (`ecp203/footing.py`) | الأبعاد من جهد التربة، القص الثاقب، القص في اتجاه واحد، العزوم والتسليح، طول التماسك |
| **القواعد المشتركة** (`ecp203/foundation.py`) | الأبعاد بحيث المحصلة في المنتصف، مخطط القص والعزم، السمك من القص الثاقب والقص، التسليح الطولي والعرضي |
| **اللبشة** (`ecp203/foundation.py`) | ضغط التربة بالطريقة الجاسئة (مع اللامركزية)، السمك من القص الثاقب عند كل عمود (داخلي/طرفي/ركني تلقائياً)، شبكة تسليح تقريبية |
| **الحوائط** (`ecp203/wall.py`) | النحافة، الطريقة المبسطة (معادلة 6-56) أو التصميم كعمود، التسليح الرأسي والأفقي (جدول 6-14) |
| **السلالم** (`ecp203/stair.py`) | سلم طولي أو درج كابولي، الأحمال على المسقط الأفقي، التسليح كبلاطة اتجاه واحد |
| **الهوردي** (`ecp203/ribbed.py`) | اتجاه واحد واتجاهين: اشتراطات الأبعاد، الأحمال، تسليح العصب كقطاع T، القص بالخرسانة، الأعصاب العرضية |
| **البلاطات** (`ecp203/slab.py`) | اتجاه واحد (السمك الأدنى، معاملات العزوم، التسليح والتوزيع)، اتجاهين (الطريقة المبسطة α و β)، شريحة بعزوم من البرنامج (للبلاطات المسطحة)، القص الثاقب للبلاطات المسطحة |

### تصميم سقف كامل (إطار مكافئ — شبكة محاور منتظمة)
| الأمر | الكود | اللي بيعمله |
|---|---|---|
| `floor_flat` (`ecp203/floor_flat.py`) | ECP 203-2020 | السمك الأدنى وأبعاد الأعمدة، تحليل كل الإطارات في الاتجاهين بكل ترتيبات الحمل الحي، تسليح شرائح العمود والوسط، القص الثاقب لكل عمود، أحمال الأعمدة |
| `floor_pt` (`aci318/floor_pt.py`) | ACI 318-19 | تحليل الإطار المكافئ بجساءة غير منشورية، عدد الإستراندات لكل إطار بموازنة الأحمال، العزوم الثانوية، مراجعة 3 قطاعات لكل بحر (إجهادات، أقل تسليح، مقاومة)، القص الثاقب لكل عمود، أحمال الأعمدة |

المحرّك المشترك في `ecp203/efm.py`، ومتراجع على حالات معروفة من الكتب.

### الكود الأمريكي — بلاطات البوست تنشن بس (`aci318/pt_slab.py`)
| الدالة | اللي بيتحسب |
|---|---|
| `check_pt_section` | إجهادات النقل والتشغيل (Class U)، أقل ضغط مسبق 0.9 MPa، حدود إجهاد الكابلات، أقل تسليح مترابط (Table 8.6.2.3)، fps للكابلات غير المترابطة، Mu مع العزم الثانوي، والتسليح العادي الإضافي المطلوب |
| `check_pt_punching` | القص الثاقب بمعادلة 22.6.5.5 للبوست تنشن (أو جدول 22.6.5.2 لو الشروط مش متحققة)، مع نقل العزم للأعمدة الداخلية |

مراجعة البوست تنشن بتشتغل على قيم جاية من برنامج التحليل (SAFE / ADAPT): القوى بعد الفواقد، والعزوم، والعزم الثانوي.

كل تقرير بيطلع فيه كل خطوة بالمعادلة والتعويض والمرجع (البند ورقم الصفحة)، وجدول تحققات (✓/✗)، وقائمة بالقيم اللي محتاجة تتراجع على PDF الكود.

## الاستخدام

### مع Claude Code (الـ Agent)
اكتب طلبك عادي، مثلاً:
> صمم كمرة 25×60 سم، fcu = 30، العزم الموجب 180 kN·m، والقص 210 kN

أو اطلب الـ Agent بالاسم: `ecp203-structural-analyst`.

### من سطر الأوامر
```bash
cd "Egyptian codes"
python3 -m ecp203 examples/beam.json -o reports/beam.md
python3 -m ecp203 examples/column.json -o reports/column.md
python3 -m ecp203 examples/footing.json -o reports/footing.md
python3 -m ecp203 examples/slab_two_way.json -o reports/slab_two_way.md
python3 -m ecp203 examples/raft.json -o reports/raft.md
python3 -m ecp203 examples/floor_flat.json -o reports/floor_flat.md   # سقف فلات سلاب كامل
python3 -m ecp203 examples/floor_pt.json -o reports/floor_pt.md       # سقف بوست تنشن كامل (ACI)
python3 -m ecp203 examples/pt_section.json -o reports/pt_section.md     # ACI 318-19
```
ملف المدخلات ممكن يكون عنصر واحد أو قائمة عناصر. الأمر بيرجع كود خروج 1 لو فيه أي تحقق فاشل.

### من Python
```python
from ecp203 import design_beam, design_column, design_isolated_footing
rep = design_column(300, 600, fcu=30, fy=400, Pu=2400, Mx=120, Hex=3200, Hey=3200)
print(rep.to_markdown())
```

## الوحدات
mm للأبعاد، kN للقوى، kN·m للعزوم، N/mm² للمقاومات، kN/m² لجهد التربة.

## ⚠️ حدود مهمة
- قيم ACI 318-19 في موديول البوست تنشن اتراجعت على صور جداول الكود الأصلية، ما عدا اللي معلّم "تحقق" (fps للكابلات المترابطة، λs، γf، وحد εt).
- نص الكود المصري المتاح نسخة OCR، وفيها جداول وأرقام مشوهة. أي معامل مكتوب `verified=False` في `ecp203/params.py` اتاخد من طبعة 2007 أو من قراءة غير مؤكدة، **ولازم يتراجع على الأصل**. التقرير بيطبعها كلها في الآخر.
- كود الأحمال 201 وكود الأساسات 202 مش موجودين. جهد التربة الصافي ووزن القاعدة والردم مدخلات من المستخدم.
- تصميم السقف الكامل بالإطار المكافئ للشبكات المنتظمة بس. البوست تنشن: fse والفواقد افتراضات لازم تتراجع، وVp مهملة في القص الثاقب، والترخيم مش محسوب.
- السلالم مالهاش باب في ECP 203 (بتتصمم كبلاطة). والقواعد المشتركة واللبشة بتفترض أساس جاسئ وتوزيع ضغط خطي، وعزوم اللبشة تقريبية، فاستخدم عزوم SAFE للتصميم النهائي. حوائط القص داخل المستوى بتتصمم بموديول الأعمدة.
- غير مغطى حالياً: الأعمدة الدائرية والحلزونية، الحوائط الساندة، الخزانات، الترخيم والتشرخ، اللي، وإعادة توزيع العزوم. وفي البوست تنشن: حساب الفواقد، والترخيم، وتحليل الإطار المكافئ.
- **الحسابات للمساعدة والمراجعة فقط، ولازم يعتمدها مهندس إنشائي مسؤول قبل التنفيذ.**
