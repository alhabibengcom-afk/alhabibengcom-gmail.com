# القسم الكهربائي — الحزمة والمراجعة والتنسيق والاستلام

## ترتيب الشوب درونج حسب الموقع
1. **قبل الصب:** شبكة التأريض والأساسات (E01)، مواسير مدفونة في البلاطات والحوائط الخرسانية، علب السقف، فتحات الصواعد والتراكات، نزلات الصواعق في الأعمدة لو مطلوبة (E03).
2. **قبل المباني والمحارة:** مواسير وعلب الحوائط (إنارة، برايز، تيار خفيف) بالمناسيب، أماكن اللوحات الفرعية ومقاساتها.
3. **قبل الأسقف:** مسارات الحوامل (Cable trays/ladders) منسقة مع الميكانيكا، الكشافات على شبكة السقف المعماري، كواشف الإنذار والسماعات.
4. **غرف الكهرباء:** المحولات/الغرف الرئيسية، لوحة الجهد المنخفض الرئيسية، المولد وخزان الوقود والعادم (E02)، الـ ATS والـ UPS — بأبعاد الصيانة والتهوية.
5. **المخططات:** Single line diagram، Riser diagram، جداول اللوحات، حسابات الكابلات والهبوط والقصر، حسابات الإنارة، أنظمة التيار الخفيف.

## قوائم المراجعة
- [ ] الأحمال: كل دائرة بقدرتها ومعامل القدرة، معامل الطلب والتنوع من الكود/المواصفات، اتزان الأوجه (`elec_calc.py panel`).
- [ ] الكابلات: التيار بعد معاملات التصحيح (الحرارة، التجميع، طريقة التركيب)، هبوط الجهد ≤ الحد، القصر (Short-circuit withstand) — `elec_calc.py cable`.
- [ ] الحماية: Ib ≤ In ≤ Iz، سعة القطع ≥ تيار القصر، التنسيق (Selectivity)، حماية التسرب RCD للدوائر المطلوبة.
- [ ] التأريض: النظام (TN-S/TT...)، قيمة المقاومة المطلوبة، موصلات الحماية والربط المتساوي للمواسير والمعدات (E01).
- [ ] الإنارة: شدة الإضاءة لكل فراغ من المواصفات/الكود (`elec_calc.py lux`)، إنارة الطوارئ ولوحات المخارج ومدة تشغيلها، التحكم (E07).
- [ ] الطوارئ: الأحمال على المولد (حريق، شفط دخان، مصاعد طوارئ، إنارة طوارئ)، الـ ATS، مدة التحويل.
- [ ] معامل القدرة والتوافقيات (E05، E06) لو أحمال كبيرة غير خطية.
- [ ] الإنذار (305/3): التغطية، المناطق، الربط مع الحريق والتكييف والمصاعد والأبواب.

## اعتماد اللوحات والكابلات والمعدات
- لوحات: Single line، الواجهة والأبعاد، القضبان (Busbar) وسعتها، القواطع (النوع، Icu)، درجة الحماية IP، شهادات الاختبار النمطي، المصنّع المعتمد.
- كابلات: المقطع، العزل، الجهد، المواصفة القياسية، شهادات المصنع، الكتالوج (سعات التيار — نفس الجدول المستخدم في الحساب).
- معدات (مولد، UPS، محول، كشافات): Data sheet، المطابقة بند بند للمواصفات، شهادات الاختبار (كشافات: كود اختبار الكشافات E14).

## التنسيق
- مع الميكانيكا: قدرة وجهد ومكان تغذية كل معدة، بادئ الحركة (E08)، لوحات التحكم، ربط BMS والحريق.
- مع المعماري: أماكن اللوحات والعلب على الحوائط وفي الفرش، الكشافات على شبكة السقف، غرف الكهرباء.
- مع الإنشائي: فتحات الصواعد والتراكات، المواسير في بلاطات البوست تنشن (قبل الصب فقط)، التأريض في الأساسات.

## الاختبار والاستلام (E12 المعتمد)
قبل التغطية: اختبار استمرارية ومقاومة عزل المواسير/الكابلات. قبل التشغيل: مقاومة العزل، الاستمرارية، مقاومة التأريض، تتابع الأوجه، اختبار الـ RCD، اختبار اللوحات (عزل، تشغيل القواطع، العزم على المسامير)، تشغيل المولد على حمل والتحويل الأوتوماتيكي، قياس الإضاءة، اختبار الإنذار بالكامل. كل اختبار بنموذج موقّع وقيمة مقاسة مقابل الحد من E12. التسليم: As-built، جداول اللوحات النهائية، الكتالوجات، O&M.
