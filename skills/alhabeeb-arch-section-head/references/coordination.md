# التنسيق المعماري مع التخصصات

السجل بـ `mep-coordination-check`، والحلول بـ `alhabeeb-clash-resolution`. أي تعارض يحتاج قرار الاستشاري يطلع RFI (`alhabeeb-correspondence-submittals`) ويتسجل في سجل المكتب الفني.

| نقطة التلاقي | المعماري | التخصص الآخر | الفحص |
|---|---|---|---|
| منسوب السقف المعلق | منسوب السقف لكل فراغ | الإنشائي: بطنية الكمرات؛ التكييف: الدكت والوحدات؛ الحريق: المواسير | قطاع تنسيق في أحرج نقطة لكل فراغ: بطنية الكمرة − (الدكت + العزل + التعليق) ≥ منسوب السقف + خلوص |
| الفتحات | فتحات الأبواب والشبابيك، الصواعد | الإنشائي: الكمرات والأعمدة والجدران الخرسانية؛ البوست تنشن: ممنوع قطع الكابلات | كل فتحة في بلاطة أو حائط خرساني متوقعة في الإنشائي قبل الصب (جلب/بلوك آوت) |
| الصواعد والدكت | أبعاد الصاعد ومكانه وفتحات الصيانة | كل الكهروميكانيكا | مساحة كافية + فصل حريق للصاعد + أبواب صيانة |
| الحوائط | نوع وسمك الحائط | الكهرباء: اللوحات والعلب؛ الصحي: المواسير داخل الحائط | سمك الحائط يستوعب المواسير/اللوحات، أو تكسية |
| الحمامات | الفرش والمناسيب والعزل | الصحي: الصرف والميول والأجهزة | منسوب البلاطة المنخفضة (Sunken) كافي لميول الصرف |
| الأسقف | RCP | الإضاءة، الرشاشات، الكواشف، التكييف | شبكة موحدة وتوزيع من غير تعارض |
| الواجهات | التكسية والشبابيك | الإنشائي: نقط التثبيت والكمرات الطرفية؛ الكهرباء: إضاءة الواجهة | نقط تثبيت متوقعة في الخرسانة |
| الأرضيات | المناسيب والتشطيب | الإنشائي: منسوب البلاطة الخام؛ الكهرباء: مجاري الأرضيات | سمك الطبقات (لياسة + تشطيب) = فرق المنسوب المعماري − الإنشائي |
| الحريق | أبواب الحريق، فصل السلالم والحوائط | أنظمة الإطفاء والإنذار، التحكم في الدخان | تطابق مناطق الحريق مع تقسيم الأنظمة |

قاعدة الأولوية عند التعارض (اقتراح للحل، والقرار للاستشاري): الإنشائي ثابت بعد الصب → الأنظمة الكبيرة بالجاذبية (الصرف) → الدكت الكبيرة → المواسير المضغوطة → الكابلات → التشطيب.
