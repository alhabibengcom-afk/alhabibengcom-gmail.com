# مؤشرات أداء المكتب الفني

الأرقام المستهدفة دي استرشادية لشغل المقاولات؛ الإدارة تعتمد أرقامها، ومدد الرد من العقد.

| المؤشر | الحساب (من السجل) | المستهدف | لو بره المستهدف |
|---|---|---|---|
| الاعتماد من أول مرة (SD، MS) | (A + B عند Rev 0) ÷ كل البنود اللي اتردّ عليها | ≥ 70% | مراجعة داخلية أقوى قبل التقديم؛ تحليل أسباب الرفض المتكررة |
| متوسط زمن رد الاستشاري | متوسط (تاريخ الإغلاق − تاريخ التقديم) | ≤ مدة العقد | تصعيد حسب الجدول؛ توثيق للمطالبة الزمنية |
| البنود المتأخرة عند الاستشاري | مفتوح وعدّى ميعاد الرد | 0 | خطاب تذكير/تصعيد |
| البنود المتأخرة عندنا (TSK، إعادة تقديم) | مهام عدّت ميعادها | 0 | إعادة توزيع أو دعم |
| زمن إعادة التقديم بعد C | (تاريخ Rev+1 − تاريخ رد C) | ≤ 5 أيام عمل | متابعة المسؤول |
| أقدم بند مفتوح | أكبر "Days open" | أقل من ضعف مدة الرد | تصعيد بالاسم |
| تغطية خطة التقديمات | المقدّم في ميعاده ÷ المخطط حتى تاريخه | ≥ 90% | تحديث الخطة مع التخطيط، أولوية للخامات طويلة التوريد |
| RFIs بأثر تكلفة/زمن | عدد وقيمة | — (للمتابعة) | فتح VO وإخطار تعاقدي في الميعاد |
| المستخلصات المتأخرة في الاعتماد/الصرف | IPC مفتوح بعد مدته | 0 | تصعيد للمالك حسب العقد |

ملاحظات قراءة المؤشرات:
- نسبة اعتماد منخفضة في تخصص واحد = مشكلة في مراجعة التخصص ده (مش مشكلة استشاري عام).
- متوسط زمن رد عالي مع قلة المتأخر = الاستشاري بيرد قبل الميعاد بشوية؛ مع كثرة المتأخر = تصعيد.
- حمل الشغل: لو أكتر من نص المتأخر عند مهندس واحد، المشكلة توزيع مش أداء.
